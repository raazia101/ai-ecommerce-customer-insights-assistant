# Customer Support FAQ

## Order Tracking

Customers can track their order from the Orders section of their account.
Each order displays its current status and the latest available delivery
information.

If a tracking number is available, it is displayed in the order details.
Customers can use the tracking number to follow the shipment with the
delivery carrier.

## Delivery Status

Order statuses may include processing, shipped, out for delivery, and
delivered.

An order marked as processing is still being prepared. An order marked as
shipped has been handed to the delivery carrier. An order marked as out for
delivery is with the local delivery service and is expected to arrive soon.

## Returns

Customers can request a return through the Orders section of their account.
The return process depends on whether the item is eligible under the return
policy.

Customers should keep the original item packaging where possible until the
return has been completed.

## Refunds

After a returned item is received and approved, the refund is initiated to
the original payment method.

The time required for the refund to appear can depend on the payment
provider or bank.

## Payment Problems

If a payment fails, customers should verify that their payment details are
correct and that their payment method is supported.

If the problem continues, customers can try another supported payment
method.

## Account Password

Customers can reset a forgotten password using the password reset option on
the account sign-in page.

A password reset link is sent to the email address associated with the
account.

## Order Cancellation

Customers may request cancellation while an order is still eligible for
cancellation.

Orders that have already progressed to shipment may no longer be
cancellable.

## Customer Support

Customers who cannot resolve an issue using the available self-service
options can contact customer support with their order number and relevant
details.
