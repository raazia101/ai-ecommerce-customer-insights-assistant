# Intern Project

## Overview

Project workspace for the internship project.

## Environment

- Python
- PostgreSQL
- MongoDB
- FAISS
- FastAPI
- OpenAI
- LangChain
- Sentence Transformers
- Streamlit

## Setup

1. Create and activate the Python virtual environment.
2. Install dependencies with:
   pip install -r requirements.txt
3. Configure local environment variables using .env.
4. Start PostgreSQL and MongoDB.
